## ✨ Why Steel Tray?

Most food delivery apps treat breakfast like an e-commerce checkout for cardboard boxes. But anyone who has ever stood by the stainless-steel delivery window of a temple-street hotel in Udupi knows:

1. **The Tray Matters:** Hot tiffins belong on a cut banana leaf lining a 5-compartment stamped stainless steel platter.
2. **The Katoris are Sacred:** Kempu (red coconut) chutney and hot drumstick sambar must have their dedicated circular wells.
3. **The Kaapi has its Place:** Strong degree filter coffee stays piping hot in a traditional brass/steel dabarah-tumbler set.
4. **The Chit is Law:** You pay, you get a printed thermal chit with your token number, and you watch the cook sizzle batter on the tawa.

STEEL TRAY brings this entire sensory ritual into an interactive web experience.

## 🚀 Key Features

- **🍱 Interactive Stainless Platter:**
  - Dynamic 5-compartment tray layout with brushed steel rim highlights and rivet accents.
  - Realistic banana leaf bed in the main compartment, twin round katori wells, and a sunken dabarah dock.
  - Interactive item removal, quantity increments (`x2`, `x3`), and live visual plating.

- **✈️ Parabolic "Serve Flight" Animations:**
  - Adding an item flings it with fluid physics from the menu card right into its designated compartment on the tray.

- **☕ Signature Coastal Menu:**
  - **Neer Dosa** (ನೀರು ದೋಸೆ) — Lacy, paper-thin rice crepes with sweet grated coconut & jaggery.
  - **Mangalore Buns** (ಮಂಗಳೂರು ಬನ್ಸ್) — Golden, fluffy fermented banana puris.
  - **Goli Baje** (ಗೋಳಿ ಬಜೆ) — Crispy outside, pillowy inside Maida fritters with ginger & green chilli.
  - **Filter Kaapi** (ಫಿಲ್ಟರ್ ಕಾಫಿ) — Frothy, aromatic chicory brew in a steel dabarah tumbler.

- **⚡ Combo Platter Builder:**
  - Upgrade solo items into full morning feasts with step-by-step customizers and live savings counters.

- **🧾 Authentic Thermal Chit Receipt:**
  - Real-time rolling odometer counter for live billing calculations.
  - Single-line confirmed slot indicator with live counter token availability.
  - Printable token slip modal with kitchen preparation steps: *Order Fired → Tawa Sizzle → Plated on Leaf*.

- **⏱️ 15-Minute Tawa Pickup Slot Reservations:**
  - Reserve exact kitchen pickup windows with live capacity tracking.

- **🎨 Retro Udupi Aesthetics:**
  - Hand-painted enamel signboard wordmark inspired by coastal Karnataka hotels.
  - Filter-coffee brown (`#2C1810`), terracotta clay (`#B5562D`), and banana-leaf green (`#295A24`) palette.
  - Bilingual typography with authentic Kannada script throughout.

## 📦 Getting Started

Clone the repository and fire up the development server:

```bash
# 1. Clone repo
git clone https://github.com/Suhaid11/STEEL-TRAY.git

# 2. Enter project directory
cd STEEL-TRAY

# 3. Install dependencies
npm install

# 4. Start the local server
npm run dev
```

Open your browser at `http://localhost:3000` (or `5173`) to start plating!

---

## 🏗️ Building for Production

```bash
npm run build
```

The optimized static assets will be output to the `dist/` directory, ready to deploy to Vercel, Netlify, or Cloud Run.
